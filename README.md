# Guanmo site

观墨（Guanmo）开源 Markdown 阅读应用的独立官网。页面采用暖白纸张感、衬线大标题和滚动叙事：首屏展示一张真实软件截图，其余能力用轻量动效表达。

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 检查

```bash
npm run lint
npx tsc --noEmit
npm run build
```

设计锁定与视觉验收记录见 [`DESIGN.md`](./DESIGN.md) 和 [`design-qa.md`](./design-qa.md)。
